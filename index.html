UC1 — Requisitos e Funcionalidades

O que são requisitos?

Requisitos são as necessidades que um sistema precisa atender. Eles mostram o que o sistema deve fazer, quais regras deve seguir e quais características precisa ter para funcionar corretamente.

Para que serve?

Serve para entender o problema antes de criar o sistema. Sem requisitos claros, a equipe pode desenvolver algo errado, incompleto ou diferente do que o cliente precisa.

Exemplo prático

Em um sistema de login, um requisito pode ser: “O usuário deve informar e-mail e senha para acessar o sistema”.

Tipos de requisitos

  • Funcionais: dizem o que o sistema deve fazer.
  • Não funcionais: dizem como o sistema deve funcionar.

Exemplo de requisito funcional

O sistema deve permitir que o usuário faça login usando e-mail e senha.

Exemplo de requisito não funcional

O sistema deve carregar a tela inicial em até 3 segundos.

Erro comum

Um erro comum é começar a programar sem entender exatamente o que precisa ser feito.

Resumo rápido

Requisitos são a base de qualquer sistema. Eles ajudam a transformar uma ideia em um projeto organizado.

UC2 — Gestão de Projetos de TI

O que é gestão de projetos?

Gestão de projetos é a organização das etapas, tarefas, pessoas, prazos e recursos necessários para entregar um projeto com qualidade.

Para que serve?

Serve para evitar bagunça, atrasos, retrabalho e falta de comunicação dentro da equipe.

Exemplo prático

Se uma equipe precisa criar um site, ela pode dividir o projeto em tarefas: criar layout, fazer HTML, fazer CSS, programar JavaScript, testar e publicar.

Scrum

Scrum é uma metodologia ágil usada para organizar o trabalho em ciclos chamados sprints. Cada sprint tem um objetivo e uma entrega.

Kanban

Kanban é um quadro visual usado para acompanhar tarefas. Normalmente ele é dividido em: 

A Fazer | Em Andamento | Concluído

Exemplo de backlog

1. Criar tela inicial
2. Criar tela de login
3. Criar dashboard
4. Criar área de pesquisa
5. Publicar no GitHub Pages

Erro comum

Um erro comum é tentar fazer tudo ao mesmo tempo, sem prioridade.

Resumo rápido

Gestão de projetos ajuda a equipe a trabalhar de forma organizada, com foco, prioridade e entregas claras.

UC3 — Algoritmos

O que é algoritmo?

Algoritmo é uma sequência de passos usada para resolver um problema. Ele pode ser escrito em linguagem simples, fluxograma, pseudocódigo ou código.

Para que serve?

Serve para organizar o raciocínio antes de programar.

Exemplo do dia a dia

1. Pegar um copo
2. Colocar água
3. Beber a água

Exemplo em JavaScript

let senha = "1234";

if (senha === "1234") {
  console.log("Acesso liberado");
} else {
  console.log("Senha incorreta");
}

Explicação do código

  • let senha cria uma variável.
  • if verifica uma condição.
  • else executa outra ação se a condição for falsa.

Erro comum

Confundir = com ===. 

// Errado para comparação
if (senha = "1234") {
  console.log("Acesso liberado");
}

// Correto
if (senha === "1234") {
  console.log("Acesso liberado");
}

Resumo rápido

Algoritmo é o passo a passo lógico para resolver um problema.

UC4 — Programação Estruturada e Orientada a Objetos

Programação estruturada

É um modelo de programação baseado em sequência, decisão e repetição. O código é organizado em blocos e funções.

Programação orientada a objetos

É um modelo de programação baseado em objetos. Cada objeto possui características e ações.

Exemplo prático

Imagine um carro. Ele pode ter atributos como cor, modelo e velocidade. Também pode ter métodos como acelerar e frear.

Exemplo em JavaScript

class Carro {
  constructor(modelo, cor) {
    this.modelo = modelo;
    this.cor = cor;
  }

  acelerar() {
    console.log("O carro está acelerando");
  }
}

const meuCarro = new Carro("Mustang", "azul");
meuCarro.acelerar();

Conceitos importantes

  • Classe: modelo para criar objetos.
  • Objeto: elemento criado a partir de uma classe.
  • Atributo: característica do objeto.
  • Método: ação que o objeto pode realizar.

Erro comum

Um erro comum é criar classes sem entender qual responsabilidade cada uma deve ter.

Resumo rápido

Programação estruturada organiza o código em passos. POO organiza o código em objetos.

UC5 — Aplicações Desktop

O que é uma aplicação desktop?

Aplicação desktop é um programa instalado ou executado em um computador, como sistemas de estoque, cadastro, vendas ou controle interno.

Para que serve?

Serve para resolver problemas específicos dentro de empresas, escolas, lojas ou ambientes administrativos.

Exemplo prático

Um sistema de estoque pode ter tela de login, cadastro de produtos, consulta de produtos, edição, exclusão e geração de relatórios.

Estrutura comum

Login
Dashboard
Cadastro
Consulta
Edição
Exclusão
Relatórios

CRUD

CRUD significa:

  • Create: criar/cadastrar.
  • Read: ler/consultar.
  • Update: atualizar/editar.
  • Delete: excluir.

Erro comum

Um erro comum é criar telas bonitas, mas sem validação dos dados.

Resumo rápido

Aplicações desktop são sistemas feitos para rodar no computador e ajudar em processos internos.

UC6 — Banco de Dados

O que é banco de dados?

Banco de dados é um sistema usado para armazenar informações de forma organizada. Ele guarda dados em tabelas, campos e registros.

Para que serve?

Serve para armazenar informações que um sistema precisa usar, como usuários, produtos, pedidos, mensagens, notas, vagas ou clientes.

Exemplo de tabela

Tabela: alunos

id | nome   | email             | curso
1  | Carlos | carlos@email.com  | TI
2  | Ana    | ana@email.com     | Web

Criando uma tabela em SQL

CREATE TABLE alunos (
  id INT PRIMARY KEY,
  nome VARCHAR(100),
  email VARCHAR(100),
  curso VARCHAR(100)
);

Inserindo dados

INSERT INTO alunos (id, nome, email, curso)
VALUES (1, 'Carlos', 'carlos@email.com', 'TI');

Consultando dados

SELECT * FROM alunos;

Atualizando dados

UPDATE alunos
SET curso = 'Desenvolvimento Web'
WHERE id = 1;

Excluindo dados

DELETE FROM alunos
WHERE id = 1;

Erro comum

Um erro comum é esquecer o WHERE no UPDATE ou DELETE. Isso pode alterar ou apagar todos os registros da tabela.

Resumo rápido

Banco de dados é a parte do sistema que guarda informações importantes de forma organizada.

UC7 — Aplicações Web

O que é aplicação web?

Aplicação web é um sistema acessado pelo navegador, como sites, dashboards, sistemas de login, lojas virtuais e plataformas online.

Para que serve?

Serve para permitir que pessoas acessem um sistema pela internet ou rede, usando computador, celular ou tablet.

Tecnologias principais

  • HTML: estrutura da página.
  • CSS: aparência e design.
  • JavaScript: interatividade e lógica.

Exemplo de HTML

<h1>Meu primeiro site</h1>
<p>Bem-vindo ao portal de TI.</p>

Exemplo de CSS

body {
  background: #020b18;
  color: white;
}

Exemplo de JavaScript

const nome = "J.A.R.V.I.S";
console.log("Sistema " + nome + " iniciado.");

Erro comum

Um erro comum é esquecer de ligar o CSS ou o JavaScript no HTML. 

<link rel="stylesheet" href="style.css" />
<script src="script.js"></script>

Resumo rápido

Aplicações web são sistemas acessados pelo navegador e construídos com tecnologias como HTML, CSS e JavaScript.
